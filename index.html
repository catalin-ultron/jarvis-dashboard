Why J.A.R.V.I.S.?

Without Jarvis

  • No visibility into active Claude Code sessions
  • No usage analytics or cost tracking
  • AI agents are invisible config files
  • No focus / productivity tracking
  • Scattered bookmarks and navigation
  • One-size-fits-all dashboard

With Jarvis

  • Real-time session monitoring with subagent tracking
  • 30-day stats: sessions, tokens, cost, model breakdown
  • Visual agent fleet with animated robot avatars
  • Built-in Pomodoro timer with vault-integrated logging
  • Unified command center with quick launch and navigation
  • Fully configurable layout, theme, and widgets via JSON

Installation

1

Prerequisites

Ensure you have Obsidian with the Dataview plugin installed and DataviewJS enabled.

2

Clone into your vault

cd /path/to/your/vault
git clone https://github.com/catalin-ultron/jarvis-dashboard.git \
  "MOCs/Jarvis Dashboard"
3

Configure your projects

Edit src/config/config.json and set your tracked Claude Code project directories. Then open Jarvis Dashboard.md in Obsidian.

Note: The dashboard auto-detects its location and resolves src/ paths relative to itself. Place it anywhere in your vault.

Platform Support

J.A.R.V.I.S. Dashboard is built for Obsidian (macOS, Linux, Windows) using the DataviewJS plugin. All code follows a modular widget architecture designed for easy porting.
